Sync

One GitHub Gist backs up both decks (two files inside it, set up once here). Latin and Greek each show their own push/pull status on their own Settings screen; this is the one place credentials are entered or shared to another device.

Pair another device

Copy a code on this device, paste it on the other one — no camera scan (Safari has never shipped the API that would need). The code carries the gist ID and token in plain sight, same trust level as copy-pasting the token itself; nothing here is encrypted beyond that.
